# Data

No raw dataset is committed. The committed derivatives are: the item files under
`artifacts/items/` (the exact texts sent, with their labels), the call logs under
`artifacts/raw/` (every request and every response, with the model version, latency and
token usage), the sealed forecasting cohorts under `artifacts/sealed/` with their SHA-256
digests, and the figure JSONs under `artifacts/figures/`. The article's numbers come from
`artifacts/figures/summary.json`.

## Model

TypeSafe System One endpoint, `POST https://api.typesafe.ai/v1/systemone`, model pinned to
`jev-1.13.0` on every call. The response `model` field is logged per call; every record in
the logs reports `jev-1.13.0`. Set `JEV_KEY` in the environment to rerun. Probabilities are
returned to 2 decimal places by the API; nothing here is more precise than that.

## Labelled sets

| Set | Source | Split and size used | Question type |
|---|---|---|---|
| Banking77 | `legacy-datasets/banking77` on Hugging Face (Casanueva et al., 2020; CC-BY-4.0) | test, 3,080 items, 77 intents | Choice |
| CLINC150 | `clinc/clinc_oos`, config `plus` (Larson et al., 2019; CC-BY-3.0) | test, in-scope only, 4,500 items, 150 intents | Choice |
| Amazon Reviews 2023 | `McAuley-Lab/Amazon-Reviews-2023`, `raw_review_Musical_Instruments` (Hou et al., 2024) | 1,000 reviews, 200 per star, from the first 20,000 streamed with 20 to 1,500 characters of text | Score, 5 levels |
| BoolQ | `google/boolq` (Clark et al., 2019; CC-BY-SA-3.0) | validation, 1,000 items | Noul |

All four are public and were published before the model was trained. They are labelled
"contaminated" in every figure: the level of calibration on them may be flattered, and they
are used for the comparisons between conditions, which contamination does not bias in the
same way.

Option descriptions are the label names with underscores replaced by spaces. No
descriptions were written by hand.

## The sealed forecasting set

Binary questions from Manifold (public API, at least 5 unique bettors) and Polymarket
(public gamma API, at least 1,000 USD volume, Yes/No outcomes), created on or after
2026-09-15, closing on or before 2026-12-31 and at least 7 days after collection. Questions
naming an AI model, product or benchmark are excluded. Metaculus was in the plan and was
dropped because its API now requires an account.

Cohort 1: 372 questions collected 2026-09-23 (56 Manifold, 316 Polymarket). Jev's
probability for each, with the model version and timestamp, is in
`artifacts/sealed/cohort-1.jsonl`; its SHA-256 is in `cohort-1.sha256` and is committed
before any question resolves. Scoring uses that file only. Cohorts 2 and 3 are scheduled for
2026-10-15 and 2026-11-05.

## Synthetic sets

`artifacts/items/probes.jsonl`: 200 known-probability probes (166 distinct texts), four
chance mechanisms, stated probabilities 0.1 to 0.9. `artifacts/items/synthetic.jsonl`: the
controlled factorial (number format, distractor length) and the Choice and Score items with
a fully stated distribution. Both are generated by the scripts and need no download.

## Rebuild

```bash
pip install numpy scipy scikit-learn requests datasets
export JEV_KEY=...
python src/build_items.py            # item files from Hugging Face
python src/sealed_collect.py 1       # sealed cohort (re-running re-asks only new questions)
python src/run_e4_probes.py          # E4
python src/run_e4b_synthetic.py      # E4b
python src/run_e5_invariance.py      # E5, noise floor first
python src/run_e1.py                 # E1, all four sets, about 9,600 calls
python src/run_e8_e10.py             # E8 and E10 from the stored responses
python src/export_figures.py         # figure JSONs and summary.json
```

Every runner skips requests already answered in its log, so a rerun after an interruption
resumes rather than repeats. The logs are append-only; `load_log` keeps the last successful
record per request.
